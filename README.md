# Gaara preview

A preview of a new portfolio for Shrishti Sharma (Gaara Studio), for review before it replaces the live site.

The scroll-driven 3D scene is built on [sen-3d-resume](https://github.com/dayinji/sen-3d-resume) by Sen Zheng, MIT licensed (see `LICENSE`). Personal content, photographs and the bust model belong to Shrishti Sharma.

```
npm install
npm run dev
```
